Painel Seeknify · conectado a /admin/metrics e /health/ready da API real do projeto · sessão de admin com renovação automática de token

Conectar à API da Seeknify

Local: porta 3001 (API_PORT no .env). Staging/produção: a URL pública do serviço apps/api no Railway.
CORS: a API só aceita chamadas de origens listadas em CORS_ORIGIN (main.ts). Adicione a origem abaixo à variável CORS_ORIGIN do ambiente (Railway) antes de conectar:
—
Login de administrador
Precisa ser uma conta listada em ADMIN_EMAILS na API (mesma regra do requireAdmin() em admin.controller.ts). O token de acesso dura 15 min e este painel o renova sozinho em segundo plano usando o refresh token — só o refresh token fica salvo neste navegador (nunca a senha).
/admin tem limite de 60 requisições a cada 15 min (main.ts). 45s usa cerca de 20, deixando folga para outros usos do admin.
Ver o que este painel lê da API
POST {base}/auth/login · POST {base}/auth/refresh · POST {base}/auth/logout 
// login: { email, password, force? }
// resposta: { ok, token, accessToken, refreshToken, expiresIn, user }
GET {base}/admin/metrics (Authorization: Bearer <accessToken>) 
{ users:{total,new7d,new30d,canceled,byStatus,
           daily:[{date,count}x14],recent:[...]},
  billing:{plans,activePayingCustomers,
           estimatedMrrCents,leadCredits,...},
  product:{...}, accountLogs:[...], adminAuditLogs:[...],
  securityEvents:[{rule,ip,path,method,createdAt}...],
  paymentIssues:{failedWebhooks:[...],rejectedPayments:[...]} }

{ ok, checks:{database,redis}, failedWebhooks,
  version:{commit,runningSince}, timestamp }
